Cas 1, Le cert est dans Current User\My → importe-le dans Local Machine :
# Exporte depuis Current User (Cert:\CurrentUser\ mais il existe aussi Cert:\LocalMachine\)
$cert = Get-Item Cert:\CurrentUser\My\0C13FBFBBFBA611D1DA4D5A5E6D7BC898BA5E9A7
Export-PfxCertificate -Cert $cert -FilePath C:\temp\cert.pfx -Password (Read-Host -AsSecureString "Password")

# Réimporte dans Local Machine
Import-PfxCertificate -FilePath C:\temp\cert.pfx -CertStoreLocation Cert:\LocalMachine\My -Password (Read-Host -AsSecureString "Password")
Cas 2, Le cert est bien là mais la clé privée est inaccessible → donne accès à NETWORK SERVICE (ou le compte qui fait tourner ton appli) :

$cert = Get-Item Cert:\LocalMachine\My\0C13FBFBBFBA611D1DA4D5A5E6D7BC898BA5E9A7
$keyPath = $cert.PrivateKey.CspKeyContainerInfo.UniqueKeyContainerName
$fullPath = "C:\ProgramData\Microsoft\Crypto\RSA\MachineKeys\$keyPath"

$acl = Get-Acl $fullPath
$rule = New-Object System.Security.AccessControl.FileSystemAccessRule("NETWORK SERVICE","Read","Allow")
$acl.AddAccessRule($rule)
Set-Acl $fullPath $acl

#-----------------------------------------------------------
# To set up HTTPS locally:
#-----------------------------------------------------------

# 1. Check if your cert is in Current User store (certmgr.msc) instead of Local Machine (certlm.msc)
#    Run: certlm.msc (Local Machine), if your dev cert isn't there, import it:

# 2. Export from Current User with private key:
certutil -user -exportpfx -p "password123" MY dc40e6b404fde6c692946efbe0e679193330e830 mycert.pfx

# 3. Import into Local Machine:
certutil -importpfx -p "password123" mycert.pfx

# 4. Grant NETWORK SERVICE read access to the private key:
#    (Find the key in: certlm.msc → Personal → Certificates → right-click → All Tasks → Manage Private Keys)
#    Add: NETWORK SERVICE with Read access

# 5. Now bind should work:
netsh http add sslcert ipport=0.0.0.0:8767 certhash="dc40e6b404fde6c692946efbe0e679193330e830" appid="{00000000-0000-0000-0000-000000000000}"

# 6. Start with HTTPS
ScriptLangCore.exe --mcp --url https://+:8767/
