# Per-suite ENVIRONMENT overrides for run-repl-tests.sh. Keep the reason on the same line.
#
# Format:  <script>.slc   VAR=VALUE [VAR=VALUE ...]   # why this is safe
#
# Use this only where the gate cannot express a build-dependent property on its own, and always
# state what the default would do instead. Prefer fixing the engine or the suite: an entry here
# means the suite is genuinely correct but needs a knob the default run does not set.
#
# Two kinds of entry, both scoped to the ONE suite on the line (never global):
#   * VAR=VALUE   , exported into that suite's environment. A runaway recursion suite depends on the
#                     catchable depth guard, so a blanket SLC_VM_MAXFRAMES would remove the protection
#                     those suites assert.
#   * TIMEOUT=SEC , the runner's per-suite timeout (default 20s), for suites that are merely SLOW.
#                     These are deliberately NOT parked in repl-test-known-fail.txt: there they would
#                     never gate anything, so a real regression in them would go unnoticed. Values carry
#                     ~2x headroom over the slowest JIT measurement (JIT is the binding platform; the
#                     same suite is faster on NativeAOT), because the measured variance is large
#                     (crash_coroutine: 22s in one run, 43s in another).
#
_vm_gen.slc   SLC_VM_MAXFRAMES=1100000   # flat generator recursion needs ~1M frames, but the JIT
                                            # default cap is 30000 (deliberate runaway guard: the
                                            # JIT process dies uncatchably at 40000-100000 levels in
                                            # re-entrant shapes). The flat in-place generator drive
                                            # is memory-bounded, not stack-bounded, verified on the
                                            # JIT Debug build: 50 passed / 0 failed in 15 s.

                                       # their activations, with room for full-gate load.
